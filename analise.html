Como a média é calculada, linha por linha?
1. filtrados = dados.filter(linha => linha.mes === mesSelecionado) Mantém somente as linhas do mês escolhido. 2. soma = filtrados.reduce((total, linha) => total + linha.valor, 0) Começa em zero e adiciona o valor de cada linha. 3. quantidade = filtrados.length Conta quantos lançamentos existem no filtro. 4. media = soma / quantidade Divide a soma dos gastos pelo número de lançamentos. 5. kpiAverage.textContent = formatarMoeda(media) Exibe o resultado no cartão como moeda brasileira.
